Summary of Changes Students Will Make to This App

Students will not rewrite this application from scratch, but they will make specific, guided modifications during the semester:

1. Session 7 & 10 (CI Automated Testing Gates): Students edit tests/test_app.py to add assert False (or flip an expected assertion) on a branch to verify that GitHub Actions halts the pipeline and blocks pull request merges on failure.

2.Session 22 (Deployment Probes & Rollbacks): Students edit app.py or apply an environment flag (SIMULATE_UNHEALTHY=true) so /health returns HTTP 502, creating the "poison payload" to verify that Kubernetes halts a rolling update without downtime.

3. Session 24 (End-to-End Promotion): Students update APP_VERSION or the root JSON response (e.g., from v1.0.0 to v2.0.0), commit it, and watch the pipeline automatically build, test, publish, and deploy the new version into production.

4. Session 25 (Prometheus Observability): Students verify that /metrics responds correctly when scraped by Prometheus and query http_requests_total to measure traffic.
